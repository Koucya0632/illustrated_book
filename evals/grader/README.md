# Vendored grader

`check-example-contract.mjs` is a byte-for-byte copy of the same file in the
`audit-tuji-atlas` Codex skill. It lives here so CI can run the eval — the skill is
installed per-machine under `~/.codex/skills` and no runner but this developer's has it.

**This is a second copy of one rule set, which is the failure this repo produces most
often.** Two things keep it honest:

- `tests/eval-grader-vendor.test.ts` compares this copy against the skill's and fails
  when they diverge. It skips when the skill is not installed, so CI stays green while a
  developer's machine catches the drift.
- Every baseline records `graderSha256`, so a run scored by a different grader than the
  baseline says so instead of quietly reporting a moved number.

Do not edit this file. Change the skill, then re-copy:

```bash
cp ~/.codex/skills/audit-tuji-atlas/scripts/check-example-contract.mjs evals/grader/
npm run eval -- --update   # re-record: the ruler changed
```
